# Create a requested wallpaper

The bundled purple Bunbun image is a starting point, not a fixed requirement. When the user requests another wallpaper:

1. Take the requested subject, colors, mood, aspect ratio, and placement from the user's words or attached reference. Only ask about an essential missing choice. For the common 16:9 desktop view, leave quieter areas behind the top bar, sidebar, conversation text, and composer; keep the main character in a region that remains visible after `cover` cropping.
2. Use an available image-generation tool for a new illustration or edit the provided image when the user asks for an edit. Follow that tool's reference-image rules. If generation is unavailable, use a user-supplied image and state the limitation.
3. Inspect the generated image before applying it: verify the subject is recognizable, the palette fits the request, and neither important details nor the face will be hidden by the app chrome. If the image is too busy under text, adjust the design or plan localized interface overlays.
4. Save the approved image in a stable local path. If publishing it, check for personal information and rights-sensitive material first. Use the actual image path in the selected native or HeiGe apply flow, and recheck the image in the Codex window after scaling/cropping.

Describe fan-inspired art accurately; do not present it as an official game image or imply affiliation. Do not regenerate an existing satisfactory wallpaper merely because this workflow exists.
